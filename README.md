# PalePortal (Paper 1.21.4)

## Сборка

Требуется JDK 21 и Maven:

```bash
mvn --batch-mode clean package
```

Готовый JAR: `target/PalePortal-1.0.0.jar`.

## Настройка

1. Установите JAR и запустите сервер.
2. Выберите два противоположных внешних угла рамки из `REINFORCED_DEEPSLATE`: наведитесь на первый и выполните `/paleportal setportal`, затем на второй и повторите команду. Это только настраивает рамку — портал не активируется.
3. Настройте пять разных музыкальных блоков командой `/paleportal setmusic`, наведясь на каждый по очереди. Все пять должны быть в пределах 30 блоков от центра рамки. Их ноты выставляются по `music.notes` из конфига.
4. Исполните мелодию, кликая левой кнопкой по блокам в выбранном порядке. Только правильная последовательность открывает портал.
5. После активации проход внутри рамки становится проходимым; пересечение плоскости рамки телепортирует игрока в мир `pale_forest` на координаты `forest.entry`. Для возврата используйте `/paleportal return`.

`music.radius: 30.0` задаёт максимальную 3D-дистанцию от центра рамки до каждого музыкального блока.
